# Master IPA Ocean

A complete interactive website for learning the **44 English IPA sounds** with an ocean-cartoon learning theme.

## Learning sections

1. **IPA Chart** — organized monophthongs, diphthongs and consonants; audio and study buttons on every sound.
2. **Learn** — search/filter, mouth-position tips, common spellings, example words, Vietnamese learner focus, shadowing sentences and personal difficult-sound marking.
3. **Flashcards** — all sounds or filtered decks, shuffle, keyboard shortcuts, audio, learned/difficult controls.
4. **Practice** — Listen & Choose, Hear & Type, and Record & Compare modes.
5. **Quiz** — 20 mixed questions covering listening, word recognition and spelling patterns.
6. **Progress** — learned sounds, difficult sounds, best quiz score, streak and progress by sound group.

## Other features

- Ocean cartoon UI using Baloo 2 + Nunito
- Light / deep-ocean mode
- Browser English speech synthesis with voice and speed settings
- Microphone self-recording; recordings stay in the current browser session
- Local progress saved with `localStorage`
- Print-friendly phonemic chart
- Installable/offline-ready PWA (`manifest.json` + `sw.js`)
- Responsive layout for desktop, tablet and mobile

## Audio note

Pronunciation audio is generated by the browser's installed English text-to-speech voices. Each IPA sound uses a pronunciation cue plus keyword/examples. No proprietary audio from the reference website is copied.
